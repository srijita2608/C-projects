# C Projects

A collection of my C programming practice and projects.

## Projects

### Calculator

A simple calculator built in C.

Supports:

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Modulo (works with decimals)

Error handling for:

- Division/modulo by zero
- Invalid number input
- Invalid operators
- Invalid power operations (NaN/infinity)

## Technologies

- C
- GCC
- Visual Studio Code

## How to Run

Compile the calculator using GCC:

```bash
gcc calculator.c -o calculator -lm
./calculator
```
